# Superstore Sales Dashboard Analysis | Power BI Project

Project Overview:

This project was completed as part of the AnalystLab Africa Internship Program — Week 4 Task: Data Visualization & Dashboarding.

The goal of this project was to analyze retail sales data from the Superstore Sales Dataset and transform raw transactional data into meaningful business insights using Microsoft Power BI.

The dashboard focuses on:

- Sales Performance Analysis
- KPI Monitoring
- Business Intelligence Reporting
- Interactive Data Visualization
- Data Storytelling

---

Dataset Used: 

Superstore Sales Dataset

The dataset contains retail business transaction data including:

- Orders
- Customers
- Products
- Sales
- Profit
- Discounts
- Regions
- Categories
- Dates

---

Tools Used

- Microsoft Power BI Desktop
- Data Visualization
- Interactive Dashboard Design
- Basic DAX Measures

---

Business Questions Answered

This dashboard answers key business questions such as:

- Which region generates the highest profit?
- Which product categories drive the most sales?
- What are the overall revenue and profitability levels?
- Which customer segments contribute most to revenue?
- What are the top-selling products?
- How do sales trends change over time?

---

Key Insights

Regional Performance

Certain regions generated significantly stronger profits, indicating better market performance.

Category Analysis

Some product categories contributed more heavily to total sales revenue.

Customer Segmentation

Consumer customers represented a major portion of total business revenue.

Product Analysis

High-performing products were identified alongside products with lower profitability.

Sales Trends

Sales performance displayed time-based patterns useful for forecasting and planning.

---

Recommendations

Based on dashboard findings:

- Expand strategies in high-profit regions.
- Optimize underperforming products.
- Review discount impact on profitability.
- Prioritize profitable customer segments.
- Use sales trends for forecasting and inventory planning.
